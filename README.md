# Nexivara

Smart Career Decision Engine for BSc/BCA Students

## Overview

Nexivara is a Flask-based career guidance platform that helps students identify suitable career paths based on:

- CGPA
- Skills
- Focus Level
- Financial Stability
- Degree
- Preferred Location

The system predicts suitable opportunities such as Jobs, Internships, Higher Studies, Certification Courses, and Government Careers.

---

## Features

### User Features

- User Registration & Login
- Password Recovery
- Career Prediction Engine
- Skill Gap Analysis
- Personalized Career Roadmap
- Opportunity Recommendations
- Review & Rating System

### Admin Features

- Admin Dashboard
- User Management
- Career Analytics
- Review Monitoring
- Career Distribution Statistics
