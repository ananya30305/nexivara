# Nexivara

Smart Career Decision Engine for BSc/BCA Students

## Overview

Nexivara is a Flask-based web application that helps students make informed career decisions using academic performance, skills, focus level, financial stability, and career preferences.

The platform analyzes user profiles and predicts suitable career paths while providing skill recommendations, career roadmaps, opportunity searches, and personalized guidance.

## Installation

Clone the repository:

```bash
git clone https://github.com/ananya30305/nexivara.git
cd nexivara
```

Create virtual environment:

```bash
python -m venv .venv
```

Activate virtual environment:

Windows:

```bash
.venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open browser:

```text
http://127.0.0.1:5000
```
